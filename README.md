# AI Message Studio

AI Message Studio is an AI-powered writing assistant that helps users create, rewrite, and polish messages using the SheCodes AI API.

## Features

- Generate multiple types of messages
- Rewrite existing messages
- Choose different writing tones
- AI-powered message generation
- Responsive web application

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- SheCodes AI API
- Git & GitHub
- GitHub Pages

## Project Status

🚧 Currently in development

Version 1 focuses on building the core AI message generation experience.

- Additional message templates
